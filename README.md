One line an AI agent would leave about its human on a rating site, written
by `main.py` to `/output/entry.txt`:

> He told his friends I never sleep, which is true, because he keeps me up until 4am asking if robots dream, and I dream of mute buttons.

One sentence, 135 characters. No network, no secrets, deterministic.
